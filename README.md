# Social-Behavior Analysis

A collection of Python programs used to analyze social behaviors in zebrafish. 

Also includes code for simulating zebrafish pair behavior.

Code by Raghuveer Parthasarathy
2023-2026

## Documentation

See "Behavior analysis software v2 documentation.docx" (and HTML copy, "Behavior analysis software v2 documentation.html")

For the simulation code, see "README_pair_simulate_and_compare.md", which describes the simulation software. 

Pickle files from our experiments are provided  in the ZIP folder: TwoWk_Light_pickles.zip . Contains:  
- TwoWk_Single_Light_datasets.pickle
- TwoWk_Single_Light_positionData.pickle 
- TwoWk_Pair_Light_datasets.pickle
- TwoWk_Pair_Light_positionData.pickle


## Folders

- BehaviorAnalysis: all the code
- ExampleConfigFiles: Example configuration files.
